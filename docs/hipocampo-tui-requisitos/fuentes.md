# Fuentes

Documentación externa en la que se apoyan las decisiones técnicas de este paquete. Verificar versiones y licencias al fijar dependencias.

- Bubble Tea (charmbracelet): framework de TUI para Go basado en la arquitectura Elm. [pkg.go.dev](https://pkg.go.dev/github.com/charmbracelet/bubbletea@v0.26.6) · [resumen del proyecto](https://awesome.ecosyste.ms/projects/github.com%2Fcharmbracelet%2Fbubbletea)
- teatest (charmbracelet/x): pruebas de programas Bubble Tea con tamaño fijo y archivos golden. [pkg.go.dev](https://pkg.go.dev/github.com/charmbracelet/x/exp/teatest) · [estrategias de prueba de TUI en Go](https://datapointchris.github.io/dotfiles/learnings/go-tui-testing-strategies)
- VHS (charmbracelet): grabación de sesiones de terminal para documentación y regresión visual. [artículo](https://dev.to/bala_paranj_059d338e44e7e/visual-regression-testing-for-clis-with-vhs-54gl)
- fsnotify: notificaciones de sistema de archivos multiplataforma para Go. [resumen del proyecto](https://summary.ecosyste.ms/projects/378649)
- Convención `NO_COLOR`: desactivar color en programas de terminal cuando la variable está definida. [lista de programas que la respetan](https://metacpan.org/pod/Acme::CPANModules::COLOR)
- SQLite en modo WAL: lectores concurrentes que no bloquean al escritor. [documentación de SQLite](https://www.sqlite.org/docsrc/artifact/c89f81aeeef8bda1) · [explicación de WAL y concurrencia](https://coddy.tech/docs/sqlite/wal-mode-and-concurrency)
